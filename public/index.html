Сервер выключен?

Эта страница может только запустить его.

Как обычному игроку зайти на сервер

Если сервер был выключен, сначала нажмите «Запустить сервер» и подождите примерно 15–30 секунд.

Java Edition

  1. Откройте Multiplayer → Add Server.
  2. В поле адреса укажите jensen-resonant.tun.ply.gg.
  3. Порт отдельно указывать не нужно. Если клиент просит порт, используйте 25565.
  4. Версия Java может быть 1.21.11. Другие версии могут подключаться через ViaVersion, но лучше использовать 1.21.11.

Bedrock Edition

  1. Откройте Play → Servers → Add Server.
  2. В поле адреса укажите chords-gameboy.tun.ply.gg.
  3. В поле порта укажите 19132.
  4. Используйте актуальную стабильную версию Bedrock. Текущий Geyser принимает современные версии из диапазона 26.40–26.60; старые версии Bedrock не поддерживаются и должны быть обновлены через официальный магазин устройства.
  5. Для входа через Floodgate аккаунт Java Edition не нужен. При первом входе зарегистрируйтесь в AuthMe командой /register ваш_пароль ваш_пароль, а затем входите командой /login ваш_пароль.

Официальная таблица совместимости Geyser: Supported versions.

Если появляется «Unable to connect to world», сначала обновите Bedrock, проверьте порт 19132 и убедитесь, что сервер был запущен кнопкой выше.
