Сервер выключен?

Эта страница не имеет доступа к админским функциям и может только запустить сервер.

Как обычному игроку зайти

Если сервер выключен, нажмите кнопку запуска и подождите 15–30 секунд.

Java Edition

  1. Откройте Multiplayer → Add Server.
  2. Адрес: jensen-resonant.tun.ply.gg.
  3. Порт: 25565 (обычно порт можно не вводить).
  4. Рекомендуемая версия: Java 1.21.11.

Bedrock Edition

  1. Откройте Play → Servers → Add Server.
  2. Адрес: chords-gameboy.tun.ply.gg.
  3. Порт: 19132.
  4. Используйте актуальную Bedrock из диапазона, который поддерживает текущий Geyser: 26.40–26.60. Старые версии обновите через официальный магазин устройства.
  5. При первом входе: /register ваш_пароль ваш_пароль, затем /login ваш_пароль.

Совместимость Geyser: официальная таблица версий.

Ошибка «Unable to connect to world» обычно означает старую версию Bedrock, неверный порт или выключенный сервер.
