# Minecraft Control Panel

В репозитории две Render-панели:

- `minecraft-control-panel-admin` — защищённая админ-панель со статусом, запуском, остановкой, рестартом, игроками, инвентарями, эндер-сундуками, статистикой, логами, CoreProtect rollback, X-ray-диагностикой, невидимостью, миром/диском и диагностикой модулей.
- `minecraft-server-launcher` — отдельная публичная страница только с кнопкой запуска и инструкцией подключения Java/Bedrock. В ней нет авторизации и нет API остановки/рестарта/логов.

## Серверные модули

На Paper 1.21.11 установлены:

- CoreProtect Community Edition 24.1 — журнал действий и rollback.
- BlueMap 5.16 — 3D-карта мира. Для загрузки обязательных ресурсов BlueMap нужно один раз принять соответствующее условие в `plugins/BlueMap/core.conf`.
- Plan 5.8 build 3638 — статистика игроков и внутренний веб-интерфейс на локальном порту 8804.
- AuthMe, Geyser/Floodgate и ViaVersion.

Инвентари, эндер-сундуки, модерационные команды и rollback отправляются через локальный RCON-канал. RCON-пароль хранится только на Minecraft-машине в `/etc/minecraft-panel/rcon.secret` и не входит в репозиторий.

## Render environment variables

Для обеих панелей нужна `MC_SSH_PRIVATE_KEY_B64`: приватный SSH-ключ, преобразованный в Base64 одной строкой. Это сделано потому, что Render иногда не принимает многострочные PEM-значения в поле переменной.

На Linux получить значение можно так:

```bash
base64 -w 0 ~/.ssh/id_ed25519
```

На Windows значение нужно получить любым локальным способом Base64 и вставить одной строкой.

Для админ-панели дополнительно:

- `PANEL_PASSWORD` — отдельный пароль админ-панели;
- `SESSION_SECRET` генерируется Render автоматически.

Панели используют `ssh.instabox.sh:2222`, пользователя Minecraft-машины и `sudo systemctl` для управления `minecraft.service`. SSH-пользователь должен выполнять эти команды без интерактивного пароля.

`exit undefined` исправлен: SSH-поток обрабатывает событие `exit`, код возврата и сетевые ошибки отдельно.

Важно: бесплатные Render Web Services могут засыпать после периода без HTTP-запросов. Публичный launcher является только интерфейсом запуска и не является постоянным watchdog-процессом.
